# Batcomputer Theme (Surveillance & HUD)

Authentic **Batcomputer Surveillance & HUD** detective theme engineered directly from **Territory Studio's** screen graphics, FUI, and computer systems in Matt Reeves' ***The Batman*** (2022).

Ref: [Territory Studio - The Batman](https://territorystudio.com/project/the-batman/)

## Authentic FUI Design Principles
- **Function Over Form:** Built around Bruce Wayne's self-engineered, obsessive Year-Two detective workflow in Gotham City.
- **Cold Subterranean Graphite Canvas** (`#08090c`): Matches CRT low-emission monitors and nocturnal feed screens.
- **Industrial Telemetry & Gridlines** (`#1e2632`, `#283344`): Quadrant dividers, camera framing brackets, and hardware switchgear.
- **Intensifier Camera Phosphor & Night Vision Cyan** (`#2dd4bf`, `#38bdf8`, `#4ade80`): Bruce Wayne's contact-lens surveillance playback footage, facial recognition grids, and ocular telemetry.
- **Forensic Threat Crimson** (`#f43f5e`): Highlighting anomalies, targets, and critical logs.
- **High-Contrast Tactical Controls:** Primary buttons feature bright neon surveillance cyan fills (`#2dd4bf`) with pitch dark void typography (`#08090c`) for high AAA contrast and zero white-on-white issues.

## Supported Tools & Installation

### Zeron
1. Clone this repository anywhere on your system:
   ```bash
   git clone https://github.com/arpitnnd/batcomputer-theme.git
   ```
2. In **Zeron**, open **Settings** (`Ctrl+,` / `Cmd+,`) -> **Appearance**.
3. Click **Add a theme** (or **+** / **Import**).
4. Select the cloned `batcomputer-theme` directory (or `./themes/batcomputer-surveillance.json`).
5. Click **Import selected**.

### VS Code
Clone or symlink this directory into your VS Code extensions folder:
- **Windows**: `%USERPROFILE%\.vscode\extensions\batcomputer-theme`
- **macOS / Linux**: `~/.vscode/extensions/batcomputer-theme`
